Answers before we start

Frequently asked
questions.

What do you need to quote my sign?+

Your logo, a photo of the intended location, approximate dimensions, project city, and desired timeline are the best starting point. If you do not know the size or sign type, we can help recommend both.

Do you install signs?+

Yes. Installation can be included for projects throughout Hampton Roads. For customers outside the region, we ship nationwide and can prepare the sign for installation by a qualified local installer.

Can I see the sign before it is made?+

Yes. The visual direction, sizing, colors, and major specifications are reviewed before production begins.

Do you make double-sided roadside signs?+

Yes. We can quote illuminated cabinets, tenant panels, pole signs, monument displays, and other double-sided applications.

Can you work from my existing logo?+

Absolutely. Vector artwork is ideal, but you can start with the best logo file you have. We will tell you if cleaner artwork is needed for production.
